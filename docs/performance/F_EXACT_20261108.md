# F-EXACT — construcción paralela exacta de pelo largo

## Estado y alcance

El camino paralelo quedó opt-in y desactivado por defecto. `LongHairSet_Build` conserva el
constructor serial y los callbacks legacy; `LongHairSet_BuildParallel` exige callback/contexto
inmutable y thread-safe, usa un scheduler privado persistente, y conserva publicación
transaccional. La selección de `MONSTER_LONG_HAIR_THREADS` es por runtime: `1` fuerza serial,
2/4/8 habilitan sólo el pool retenido con ese tamaño y un cambio incompatible cae a serial.
No se cambia el entorno global ni se programa trabajo gráfico desde workers.

Las raíces permanecen seriales; colisión/certificación y folículos se dividen por guía con una
barrera completa entre fases. Se mantienen el orden aritmético local, auditoría de 72 muestras,
umbral `.0005*scale`, filtros/reintentos, descriptores, identidades, campo combinado exacto
`min(body, jaw snapshot)` y las 80 filas GPU por guía. El scheduler y el contexto jaw se conservan
hasta el join; el camino sin perfilado no lee el reloj ni actualiza contadores.

## Verificación

- `make -j2 test`: **PASS** (suite completa). Hubo fallos transitorios anteriores en pruebas
  asíncronas y en el test de persistencia basado en el contador global de hilos; este último se
  sustituyó por una comprobación directa de identidad `pthread_t` por partición durante 100 jobs.
  La ejecución final pasó todas las suites.
- `make editor-test`: **PASS**, 10 pruebas.
- ASan+UBSan focused scheduler/concurrency: **PASS**, fugas habilitadas.
- TSan focused scheduler/concurrency: **PASS** con
  `setarch "$(uname -m)" -R`; el arranque normal del TSan en este host falla con
  `unexpected memory mapping` (limitación del runtime TSan/ASLR).
- Diferencial contra `LongHair.c` original congelado en
  `92c7c8feff89f9a0ee852b7140e0313ac4c19e45`: **116 escenarios PASS**, dos recetas (caballo y
  perro), cuatro etapas, 21 edades forward, 21 reverse y 12 edades aleatorias por especie.
  Comparó, sin padding indeterminado, campos de cada raíz/guía, puntos, correcciones, clearance,
  folículos, flags/decisiones, colliders, descriptores/huellas y pack GPU completo bit a bit para
  serial original, serial actual y 1/2/4/8 participantes. También se probaron submitters
  concurrentes independientes y rollback por entrada inválida.
- La comparación de producción verificó digest de pack, IDs estables, conteos y claves de muestra
  para las 335 filas medidas por brazo (20 muestras de etapa y 315 filas de trayectorias).
  Todas las salidas de `current-1t/2t/4t/8t` coincidieron con el binario original.

## Medición de producción

Comando ejecutado mediante `run-bench.sh`:

```sh
python3 tools/benchmark_long_hair_parallel.py \
  --binary ./benchmarks/benchmark_long_hair_parallel \
  --reference /mnt/storage/monster-engine-agents/scratch/recovery-20261108/f-exact/base-92c7c8f/benchmarks/benchmark_long_hair_parallel \
  --recipe docs/validation/long-hair-styling/caballo-crin-foliculos.creature.json \
  --outdir /mnt/storage/monster-engine-agents/scratch/recovery-20261108/f-exact/official-production \
  --warmups 3 --samples 5 --growth-warmups 3 --growth-samples 5
```

El harness mide `MonsterVisual_UpdateLongHair` sin profiling: las cuatro etapas oficiales y
trayectorias forward/reverse/seeded-random de 21 edades; cada brazo usa 3 warmups y 5 muestras
por etapa y por trayectoria. Receta: 288 guías visibles y 9,216 hijos válidos. Host Linux
x86_64, 12 CPUs lógicas, GCC 13.3.0, `-Wall -Wextra -Wpedantic -O2`; benchmark headless, sin
mesh worker simultáneo. p95 usa nearest-rank; con n=5, p95 coincide con el máximo.
